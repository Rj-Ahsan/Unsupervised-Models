# 🤖 Unsupervised Machine Learning Models

A practical **Machine Learning repository** exploring unsupervised learning techniques for discovering hidden patterns, groups, and structures within unlabeled datasets.

This project contains implementations and experiments with multiple **clustering algorithms**, along with exploratory analysis on real-world datasets.

## 📌 Overview

Unsupervised learning is used to analyze data when target labels are not available. This repository demonstrates how clustering algorithms can identify naturally occurring groups and relationships within datasets.

### Algorithms & Techniques

* **K-Means Clustering**
* **Hierarchical Clustering**
* **DBSCAN**
* Clustering evaluation and visualization
* Exploratory Data Analysis
* Data preprocessing and feature analysis

## 🧠 Algorithms

### K-Means Clustering

Partitions observations into a predefined number of clusters by minimizing the distance between observations and their assigned cluster centroids.

### Hierarchical Clustering

Builds a hierarchy of clusters and can be visualized using a **dendrogram** to understand how observations group together.

### DBSCAN

A density-based clustering algorithm that identifies dense regions of data while also detecting potential noise and outliers.
